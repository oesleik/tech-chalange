# ADR-011 - Uso de serviços AWS

**Status:** Aceita  
**Data:** 26/10/2026  
**Participantes:** Augusto, Claudio, Daniel, Fernando, Oeslei  

## Contexto

É necessário utilizar serviços de nuvem para hospedar a aplicação, gerenciar a autenticação via Lambda e integrar com o banco RDS. A implantação deve centralizar o tráfego e segmentar recursos de rede; disponibilidade e escala precisam ser descritas conforme a configuração efetiva.

## Decisão

Usar os serviços da **AWS** para hospedar e gerenciar a aplicação:

- **EKS** para a aplicação PHP, com gerenciamento de contêineres e HPA de pods.
- **Lambda** para a autenticação, permitindo execução serverless e integração com o RDS.
- **RDS (MySQL)** para o banco de dados, em sub-redes privadas e com armazenamento criptografado.
- **API Gateway** como ponto de entrada público único, roteando requisições para a Lambda ou para o EKS conforme necessário.
- **VPC e sub-redes privadas** para isolar o banco de dados e os recursos internos, garantindo segurança.
- **New Relic e CloudWatch** para observabilidade, conforme disponibilidade dos recursos de integração.

O estado atual não equivale a uma configuração de alta disponibilidade ponta a ponta: o RDS é Single-AZ, sem backups automatizados ou snapshot final automático, e o node group tem limite próprio, separado dos HPAs de pods. Ver [ADR-007](007-rds-mysql.md) e [ADR-012](012-hpa.md).

## Consequências

- A aplicação e os serviços associados ficam centralizados na AWS, facilitando gerenciamento e integração.
- A segmentação de rede e os security groups limitam o acesso ao banco e ao NodePort.
- O HPA pode ajustar réplicas dos pods conforme métricas; a Lambda escala por modelo serverless. O node group EKS não escala automaticamente na configuração Terraform atual.
- A disponibilidade e recuperação do RDS são limitadas pela configuração Single-AZ e pela ausência de backups.

## Alternativas consideradas

- **Hospedagem em outro provedor de nuvem:** poderia usar outro provedor, mas perderíamos a integração nativa com os serviços AWS já utilizados.
