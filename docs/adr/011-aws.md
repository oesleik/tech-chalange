# ADR-011 - Uso de serviços AWS

**Status:** Aceita  
**Data:** 26/10/2026  
**Participantes:** Augusto, Claudio, Daniel, Fernando, Oeslei  

## Contexto

É necessário utilizar um serviço de nuvem para hospedar a aplicação, gerenciar a autenticação via Lambda e integrar com o banco de dados RDS, garantindo segurança, escalabilidade e centralização do tráfego.

## Decisão

Usar os serviços da **AWS** para hospedar e gerenciar a aplicação:

- **EKS** para a aplicação PHP, garantindo escalabilidade e gerenciamento de contêineres.
- **Lambda** para a autenticação, permitindo execução serverless e integração com o RDS.
- **RDS (MySQL)** para o banco de dados, garantindo alta disponibilidade e segurança.
- **API Gateway** como ponto de entrada público único, roteando requisições para a Lambda ou para o EKS conforme necessário.
- **VPC e sub-redes privadas** para isolar o banco de dados e os recursos internos, garantindo segurança.

## Consequências

- A aplicação e os serviços associados ficam centralizados na AWS, facilitando gerenciamento, monitoramento e escalabilidade.
- A segurança é reforçada com isolamento de rede, controle de acesso e execução serverless para a autenticação.
- A arquitetura permite escalabilidade automática tanto para a aplicação PHP no EKS quanto para a Lambda, otimizando custos e desempenho.

## Alternativas consideradas

- **Hospedagem em outro provedor de nuvem:** poderia usar outro provedor, mas perderíamos a integração nativa com os serviços AWS já utilizados.
