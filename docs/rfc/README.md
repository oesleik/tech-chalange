# RFCs - Requests for Comments

Esta pasta reúne propostas técnicas formalizadas para as decisões mais relevantes da solução. Como as escolhas aqui descritas já estão implementadas, os documentos foram consolidados como **aceitos** a partir do estado atual do projeto; eles não afirmam que houve uma rodada histórica de comentários.

O RFC registra contexto, alternativas e trade-offs. O ADR relacionado registra a decisão arquitetural permanente e suas consequências.
